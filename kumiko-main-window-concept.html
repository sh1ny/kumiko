1Navigate without losing your place
Project names restore their own tabs and tools. Chevrons only expand. A workspace focuses its existing session; it does not launch a new one.
2Work in independent panes
Tasks and project chat are full main tabs. The private coding session and terminal stay beside them. Split grips show intended resizing; they are not draggable here.
3One contextual tool at a time
Tasks belong to the project. Files, changes and branch PRs follow the focused workspace. Click a task or file to open it; repeat clicks focus the same tab.
