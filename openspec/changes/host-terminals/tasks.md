## Test map

Test locations:
- `process_containment`: `packages/process_containment/test/pty_test.dart` (POSIX and Windows PTY spawn, resize, I/O, shim) and `pty_windows_test.dart` (`@TestOn('windows')`: ConPTY close, conhost).

- `domain`: `packages/domain/test/profile_test.dart` (pure profile model and validation).
- Host: `packages/host/test/store/migrations_test.dart` (v3); `packages/host/test/it/profiles_test.dart`, `terminal_test.dart`, `terminal_close_test.dart` and `terminal_qualification_test.dart`. These run the real host executable through `support/desktop_standin.dart`, with test faults from `tool/kumiko_host_test.dart` and fixture shells and programs under `packages/host/test/it/fixtures/`.
- Desktop: `packages/desktop/test/terminal_test.dart` (widget tests over the scripted `HostLink` and a fake `TerminalSurface`); `packages/desktop/integration_test/terminal_test.dart` and `terminal_reopen_test.dart` (real app and bundled host).
- Engine bar: `packages/desktop/integration_test/terminal_bar_test.dart` (agent-scripted bar items through the adopted engine), and `tool/check_spike_results.dart` (mechanical check of `spike-results.md`). It reports **ADOPTABLE** when every item on every OS is `pass`, except Linux or macOS user-verified items, which may be `unproven` (each one listed). It reports **QUALIFIED** only when nothing is `unproven`. Any `fail`, blank, Windows `unproven` or agent-scripted `unproven` fails the check.
