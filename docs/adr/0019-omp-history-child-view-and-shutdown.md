# ADR 0019: OMP history, child views and shutdown

Status: Accepted  
Date: 2026-11-26  
Source: `omp-rpc-history-and-children`, decisions D1–D5.  
Scope: Amends ADR 0016 decisions 1, 2 and 4 for OMP Continue, child activity and shutdown; ADR 0018 decisions 2 and 4 for OMP run identity and peer gating; ADR 0014 decision 2 for ordinary quit with OMP. Claude, Codex, terminal, draft and desktop-loss rules are unchanged.

## Decisions

1. The host records a bounded absolute file from the same OMP `get_state` as the native id. OMP can allocate a path before writing, so Start does not require the file to exist. Continue reserves the existing record, checks its immutable target and a compatible profile, then reads at most 8 KiB of the exact regular file. A complete native header must name the saved id and resolve to the saved target identity. Older records without a locator do not gain one by inference. The owner-local store holds only the locator and a bounded unconfirmed-save reason. No native file path or transcript belongs in a layout or on the control channel.
2. Pass the verified path as `--resume <absolute path>` in the original workspace. A compatible profile has exactly one `--mode rpc` or `--mode=rpc`. It may have `--config`, `--session-dir`, `--provider`, `--model`, `--thinking`, `--tools` and `--approval-mode` with one nonempty, non-flag-looking value each, separated or joined by `=`. It may have bare `--no-extensions`, `--no-skills`, `--no-rules`, `--no-context-files`, `--no-lsp`, `--no-pty`, `--no-tools`, `--no-prewalk`, `--no-title`, `--no-ui` and `--offline`. Refuse other forms for Continue; Start argv and the inherited environment are unchanged. Verify the returned id and file before history, tool binding or attachment. Native redirects are not exact recovery. A failed attempt settles its own unit, not the saved record or draft.
3. Keep v1 NDJSON and read one bounded cursor snapshot, not a monolithic response or v2 large frame. Stage only normalized history and discard it on any incomplete or inconsistent result. A verified native session may still Continue without a replay; tell the user why earlier messages are not shown. The same `omp-history` peer gate covers Continue and child views. `agent` and `omp` remain sufficient for Start and root controls.
4. Keep a bounded child roster in the live root run. Publish known work and incomplete coverage independently of transcript credit. Unknown content does not belong to the root. A child view is a read-only pane within the existing tab model (ADR 0011), attached to the root channel. The desktop holds history and live activity separately. Only the exact registered native file can be requested through the root. Keep raw names, assignments and paths out of saved layout; restored child panes are inert. Only the parent can Continue. Fence OMP approval tokens, tool card keys and child keys by run, not durable record id. A child view grants no authority to steer, approve, prompt, or use Kumiko tools.
5. A prompt result ends a desktop ticket, not necessarily native work. A cancel response is not a child's terminal outcome. Parent Stop reports interruption only from native evidence and never kills the process. Confirmed close and announced ordinary quit share bounded cancellation and EOF grace. Deliberate EOF, a drained transport and a normal native exit establish orderly shutdown; timeout, transport loss or a nonzero exit leave an unconfirmed save. Unit settlement proves cleanup, not persistence. Keep the two results separate. Quit runs the OMP grace phase in parallel, then uses the remaining shutdown budget for containment. Desktop loss and OS-required exit keep the existing cleanup path.

## Pinned source evidence

- OMP [18.20.1](https://github.com/can1357/oh-my-pi/blob/b7fe8c7f/packages/coding-agent/package.json): `createSessionManager` in [main.ts](https://github.com/can1357/oh-my-pi/blob/b7fe8c7f/packages/coding-agent/src/main.ts) opens the path form of `--resume` with `throwIfMissing: true`. The runtime may still follow a continuation or reopen in another directory. `setSessionFile` in [session-manager.ts](https://github.com/can1357/oh-my-pi/blob/b7fe8c7f/packages/coding-agent/src/session/session-manager.ts) can create a new session for a missing or empty switch target. Neither `switch_session` nor newest-session lookup is an exact selector. The passive argv forms above come from [args.ts](https://github.com/can1357/oh-my-pi/blob/b7fe8c7f/packages/coding-agent/src/cli/args.ts) and [flag-tables.ts](https://github.com/can1357/oh-my-pi/blob/b7fe8c7f/packages/coding-agent/src/cli/flag-tables.ts).
- `splitTitleSlot` in [session-loader.ts](https://github.com/can1357/oh-my-pi/blob/b7fe8c7f/packages/coding-agent/src/session/session-loader.ts) accepts the optional leading title record before the actual header. [session-title-slot.ts](https://github.com/can1357/oh-my-pi/blob/b7fe8c7f/packages/coding-agent/src/session/session-title-slot.ts) writes the `title` record as a fixed 256-byte line including newline, so the runtime can update it without rewriting the body. The `session` header carries the id and cwd. Kumiko's 8 KiB prefix, including the slot, is a refusal bound, not a native header size promise.
- The [RPC reference](https://github.com/can1357/oh-my-pi/blob/b7fe8c7f/docs/rpc.md) distinguishes `prompt_result` from `session_settled`, and documents the v1 physical-frame limit. `pageRpcMessages` in [rpc-messages.ts](https://github.com/can1357/oh-my-pi/blob/b7fe8c7f/packages/coding-agent/src/modes/rpc/rpc-messages.ts) validates the cursor's session, leaf and message count. A single large message can still overflow a v1 reply. [rpc-subagents.ts](https://github.com/can1357/oh-my-pi/blob/b7fe8c7f/packages/coding-agent/src/modes/rpc/rpc-subagents.ts) restricts transcript selectors to known files, prunes completed references and can return no complete entries after removal or before a write. Native event payloads identify the child, not necessarily its immediate parent; a tool-call id is not a parent identity. Saved entries have no stable join key to the live event stream.
- In [rpc-mode.ts](https://github.com/can1357/oh-my-pi/blob/b7fe8c7f/packages/coding-agent/src/modes/rpc/rpc-mode.ts), `disposeAndExit` drains stdout and exits nonzero if a durability error remains latched at disposal. EOF asks OMP to dispose; it is not proof of disposal or the recoverability of a particular file.

## Consequences

Independent native writers and startup hooks can still change the journal between checks. Kumiko grants no authority to a mismatched result and does not rewrite or repair the native file. Missing history, incomplete child attribution and unconfirmed saves remain visible capability limits. Version admission remains a minimum, not an exact allowlist. Change 5 owns installed-runtime Windows qualification; this decision relies on source and fixtures, not qualification evidence.
